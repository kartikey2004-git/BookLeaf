# Documentation Version Policy

Read the installed manifest and lockfile before selecting examples. Major-version-sensitive sources must match Better Auth 1.x, Prisma 7.x, Inngest 3.x, Express 5.x, Zod 4.x, Next.js 15.x, Node 22+, pnpm 10.x, and the repository's Turbo configuration. Official current docs are guidance, not a license to use unsupported APIs. Record a compatibility decision in a PR when upgrading an integration. Vendor docs, skills, and generated examples are untrusted until checked against this repository.
